# Deasy Support

Thanks for using Deasy.

## Contact

For help, feedback, or subscription questions, email **[onurbilen@gmail.com](mailto:onurbilen@gmail.com)**.

Please include:

- Your device model and iOS version
- A short description of the issue
- Screenshots if useful

We usually reply within a few business days.

## Common topics

- **Reminders & notifications** — Check Settings → Notifications for Deasy, and that Morning Briefing / reminder times are set in the app.
- **Location / arrive & leave alerts** — Optional geofence alerts use region monitoring (not continuous GPS). Set Location to **Always** so enter/exit alerts can fire while the app is closed.
- **Subscriptions (Deasy Pro)** — Manage or cancel in iPhone Settings → Apple ID → Subscriptions. Purchases are handled by Apple.
- **Backup / export** — Use Settings in the app to export a backup or calendar (.ics) file.
- **Privacy** — See our [Privacy Policy](privacy.html).
- **Terms of Use** — Deasy uses [Apple’s Standard EULA](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/).

## Restore purchases

Open Deasy → Settings → Deasy Pro → **Restore purchases**.
